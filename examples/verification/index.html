검증 범위

수명 관리의 날짜와 만료 시간은 임시 저장소의 과거 메타데이터 및 브라우저 시계로 재현했습니다. 실제 공지 기간을 기다린 시험은 아닙니다. 호환성 범위·격리 규칙을 검사하지만 임의의 서비스 코드 전체의 동작을 보증하지 않습니다. 사용자별 구독은 20번에서 별도로 검증했습니다. DB는 기존 설계안 단계입니다.

이 예제들은 교육용 고정 revision 1.0.0입니다. 과거 모든 시점의 원본 저장소가 아니라, 현재 코드와 보존된 소스맵으로 상황별 소스를 재구성했습니다.

다시 검증하기

개별 예제 폴더에서 npm test와 npm run pins를 사용합니다. 아래 명령은 전체 확인용이며 개별 실행의 의존성이 아닙니다. Python 3, Node, Chrome 및 채워진 npm 캐시가 필요합니다.

# examples 폴더에서
python3 verification/run-all.py
python3 verification/verify-isolation.py

검증 도구의 NPM_CACHE와 CHROME_EXECUTABLE_PATH 환경 변수로 환경을 지정할 수 있습니다.
