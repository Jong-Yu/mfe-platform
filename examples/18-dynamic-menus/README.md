# 관리 화면에서 서비스·메뉴 등록

먼저 `docs/index.html`을 브라우저에서 여세요.

```sh
npm --prefix integration ci
npm start
```

소스 개발: `npm run setup` → 수정 → `npm run build -- service-a` → `npm run select -- baseline`.
검증: `npm test`. 고정 상태 비교: `npm run pins`. 초기화: 서버·탭을 닫은 후 `npm run reset`.

이 폴더 하나를 복사하여 사용할 수 있습니다. 다른 예제를 실행할 필요가 없습니다. 사용자별 구독은 포함하지 않습니다.
