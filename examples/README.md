# 독립 MFE 예제

처음 공부할 때는 **[한 파일로 읽는 통합 학습서](../docs/mfe-self-study.html)**에서 시작하세요. 기초 개념, 권장 순서, 실습과 해설, 20개 예제의 상세 설명을 모두 포함합니다.

브라우저에서 `index.html`을 열면 읽는 순서, 20개 예제와 실행 방법을 볼 수 있습니다. 각 예제 폴더 하나만 복사해 사용할 수 있습니다.

`verification/index.html`은 실제 실행·분리·재빌드 결과입니다. `verification`의 일괄 검증 도구는 개별 예제 실행에 필요하지 않습니다. 사용자별 구독은 `20-user-subscriptions`에서 별도로 실행합니다.
