통과 20/20

무엇이 독립되었나

각 예제는 자체 projects, integration 서버, 소스·설정·lockfile, vendor 도구, 초기 저장소, 실행 스크립트, 검증 코드와 HTML 설명서를 가집니다. 상위 프로젝트나 다른 예제의 코드·latest 파일을 읽지 않습니다. npm workspace, 소스 심볼릭 링크, 공유 실행 저장소도 사용하지 않습니다.

공통 기반이 필요한 경우 같은 코드를 각 폴더에 복사했습니다. 예제마다 파일이 독립되어 있으므로 한쪽 SDK나 서버를 바꾸어도 다른 예제에는 전달되지 않습니다. 각 서비스 역시 자체 package.json·lockfile을 가진 독립 프로젝트입니다.

빌드 도구 1.7.1에서는 재시도 모듈의 소스맵에 상대 경로를 기록하도록 수정했습니다. 폴더를 옮겨 다시 빌드해도 같은 배포 파일이 생성되도록 하기 위한 변경입니다.

제공된 기준은 example.lock.json의 파일 해시와 seed-store의 배포 조합으로 고정했습니다. 실행용 artifact-store는 분리되어 있습니다. 수정 후에는 npm run pins가 차이를 보여 주며, npm run reset은 실행 저장소만 복원합니다.

과거 모든 시점의 원본 저장소가 보존된 것은 아니므로, 현재 소스와 보존된 소스맵을 바탕으로 상황을 재구성한 revision 1.0.0입니다. 운영 관리의 기반 기능은 해당 그룹 안에 함께 들어 있습니다. 사용자별 구독은 독립 예제 20번에 추가했습니다. 기존 01~19번의 고정 파일은 유지했습니다. DB는 설계안만 있으며 실제 DB 구현 예제는 없습니다.
